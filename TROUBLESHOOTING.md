# SainikNext AI - Troubleshooting Guide

This guide covers common runtime errors, configuration mismatches, and steps to resolve them.

---

## 1. System Health Indicators are Yellow/Red

The system status bar in the top header monitors subsystems via `/health`. Here is how to diagnose failures:

### 🔴 Database Indicator (Red)
- **Cause**: FastAPI cannot connect to PostgreSQL.
- **Resolution**:
  - Check if `DATABASE_URL` is set correctly in your `.env`.
  - In local development, verify your Docker container is running (`docker ps`).
  - If a production Postgres server is down, SainikNext automatically falls back to a local SQLite database (`backend/database/users.sqlite`) to prevent server crashes, but status telemetry will report `degraded` or `error`.

### 🟡 AI Indicator (Yellow / Degraded)
- **Cause**: The Gemini API key is missing, invalid, or quota-limited.
- **Resolution**:
  - Ensure `GOOGLE_API_KEY` is present in the environment and starts with `AIzaSy`.
  - If the key is valid, check your Google AI Studio billing dashboard for quota limits or rate limit errors.
  - While in fallback mode, the backend uses deterministic rule-based mapping to prevent application failures.

## 2. Google OAuth Redirect Mismatches (400 / 500 errors)

### Error: "OAuth not configured"
- **Cause**: `GOOGLE_CLIENT_ID` or `GOOGLE_CLIENT_SECRET` are not set in the environment.
- **Resolution**: Obtain credentials from the GCP Console and populate the `.env`.

### Error: "Redirect URI mismatch"
- **Cause**: The redirect URI generated by FastAPI does not match the authorized redirect URIs configured in the Google Cloud Console.
- **Resolution**:
  - Go to Google Cloud Console > APIs & Services > Credentials > OAuth 2.0 Client IDs.
  - Add the authorized redirect URIs:
    - Development: `http://localhost:8000/auth`
    - Production: `https://your-production-backend-domain.com/auth`

## 3. Playwright & Job Scraper Failures

### Error: "Chromium executable not found"
- **Cause**: Playwright has been installed via pip, but the browser binaries have not been downloaded.
- **Resolution**:
  - Run the following command inside the backend environment to download the browser engines:
    ```bash
    playwright install chromium
    ```
  - In Docker environments, ensure the Dockerfile contains `RUN playwright install-deps chromium` to install all underlying Linux shared libraries.

## 4. SentenceTransformers Model Loading Timeouts

### Symptom: First API request takes 20-30 seconds or times out
- **Cause**: The server is downloading the `all-MiniLM-L6-v2` embedding model (approx 90MB) on demand.
- **Resolution**:
  - By default, our `backend/Dockerfile` pre-downloads and bakes the model into the container image during the build phase.
  - For local development, run a simple python query once to preload it:
    ```bash
    python -c "from sentence_transformers import SentenceTransformer; SentenceTransformer('all-MiniLM-L6-v2')"
    ```
